## 2. 来源、端点和覆盖结果

### 2.1 深交所官方月历：`adopt`（仅本轮覆盖事实）

第一方端点：

`https://www.szse.cn/api/report/exchange/onepersistenthour/monthList?month=YYYY-MM`

逐月 GET 48 个月；每个月要求 `data` 恰好包含该月每个自然日一次、日期无重复、`jybz` 只能为 0/1。结果：

| 年份（窗口内） | 开市 Session |
| --- | ---: |
| 2022-10～12 | 60 |
| 2023 | 242 |
| 2024 | 242 |
| 2025 | 243 |
| 2026-01～09 | 181 |
| 合计 | **968** |

48/48 月通过完整自然月校验，覆盖 **1,461 个自然日**、968 个开市日、493 个闭市日。没有以工作日、腾讯有行情的日期或其他交易所日历代替官方日历。

`adopt` 只表示这组已冻结响应可用于本轮对齐审计；不是交易时段/半日安排的完整证明，也不是自动化使用许可结论。历史规则有效版本和许可仍见下文。

### 2.2 TDX 全市场逐日包：`unresolved`

第一方端点：

`https://www.tdx.com.cn/products/data/data/g4day/YYYYMMDD.zip`

为避免把未取得官方日历的日期误判为休市，对窗口内全部 **1,461 个自然日**各执行一次 HEAD，再与官方日历对齐：

| 官方日历 | HEAD 200 且传输成功 | HEAD 404 且传输成功 | 传输失败 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 开市 | 922 | 0 | **46** | 968 |
| 闭市 | 0 | 474 | **19** | 493 |
| 合计 | 922 | 474 | 65 | 1,461 |

传输失败共 40 次 curl exit 35（TLS）和 25 次 exit 28（超时）。**46 个开市日未能证明包可得，也未能证明源端缺包**；完整日期清单见 `summary.json` 的 `tdx_head_non200_dates`，每次失败见请求日志。不能把失败归为 404、休市或源端不存在。

另对 11 个日期 GET：2022-10-10；2024-08-19/20/27/28；2025-12-05/08/09；2026-09-04/07/30。6 个完整下载通过 ZIP 全成员 CRC 校验，各含 6 个成员；5 个虽收到 HTTP 200，仍因传输超时未获得完整包。完整包日期为 2024-08-19、2024-08-28、2025-12-05、2025-12-09、2026-09-07、2026-09-30。

**HEAD 成功不是包内容已验证。** HEAD 的 `sha256` 是 curl 保存的 HEAD 响应字节摘要，不是 ZIP 内容 hash；完整 GET 才有原包 hash。未逐日下载/解压全部 968 个包，未验证每天的深市成员覆盖和条数，不能将 922 个 HEAD 200 写成“922 个全市场包内容通过”。

### 2.3 腾讯/TDX 单位规范化与特殊样本：`unresolved`

第一方端点：

`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=szCODE,day,START,END,640,`

按 spec 中的控制样本选择 `159919`（分红候选）、`159522`（停牌/终止候选）、`159560`（折算候选）。这些事件身份/日期首先来自 spec，**本轮未通过完整官方公告链独立确认**。每个代码请求 2024-08-01～30、2025-12-01～12、2026-09-01～30，合计 9 次，全部 HTTP 501、非预期行情 JSON。

30 个计划的代码/日期对拍格子因此全部 `unresolved`，**0 个完成双源对拍**。不能宣称 OHLC 或成交量一致，不能把缺行当停牌，也不能根据原始价格跳变推断分红/折算。

拟核验的方法与旧路径保持一致：TDX 深市 `.cod` 150 字节记录用 offset 32 的小端序号定位 `.md1` 512 字节价格块；OHLC offset 为 12/20/28/36（float64），成交量 offset 56（uint64）。腾讯 day 行顺序为日期/open/close/high/low/手，拟乘 100 转份，OHLC 按 0.001 元 tick 对齐后完全比较，成交量按整数份完全比较，不设百分比容差。**本轮没有成功配对，故该方法及 ETF 单位解释尚未获得此次实测确认；tick/适用规则亦须官方证据。** 不据此启用 P11。

即使未来两源一致，也只能说明供应商输出一致，不自动证明双方上游独立或证明开盘时可以成交。成交额不从腾讯估算补入。

### 2.4 cninfo 公告种类与分页：`unresolved`

第一方端点：

`POST https://www.cninfo.com.cn/new/hisAnnouncement/query`

参数包括 `column=szse`、`plate=fund`、`tabName=fulltext`、`pageSize=30`、`sortName=time`、`sortType=asc`。完整表单在逐请求日志中；本轮尚未验证该组合的基金过滤语义，不能仅凭参数名认定返回集合正好是所需历史深市 ETF。

- 10 个查询词各取第 1、2 页：上市交易公告书、基金合同、招募说明书、标的指数、终止上市、基金合同终止、分红、折算、停牌、复牌。窗口为 2022-10-01～2026-09-30。
- 对唯一返回正计数的“复牌”另探测第 1、47、48 页，核查报告页数的边界。
- 对 `159919`、`159522`、`159560` 分别做 2000-01-01～2026-09-30 的代码关键词控制查询，以检查窗口前公告入口；未将关键词搜索视为精确证券过滤。

合计 **26 次请求：22 次 HTTP 403；4 次 HTTP 200 且可解析**。三个 200 返回零记录；“复牌”第 2 页返回 30 条、总数 1,410、页数 47、`hasMore=true`，但第 1/47/48 页均 403。**没有任何一类公告完成连续分页、唯一 ID 去重和总数核对。**

零记录不证明不存在：查询语义、索引覆盖和历史归档均未验证。窗口内关键词还不足以查全窗口前已上市基金的合同/上市公告。类别变更亦不能用“标的指数”一个词替代完整事件分类。未验证公告附件、类别变更、合同终止同义词以及登记/除息/发放或折算比例字段的完整提取。

所以 P8 的 PIT 类别/指数、P10 的开盘停复牌证据、P15 的 Risk Exit 和 P21 的公司行动完整性均不可由本次结果签字。日期粒度公告仍须遵守 P6：不能把本地 `observed_at` 或公告日期 00:00 回填为历史开盘前已知。

### 2.5 159000～159999 历史扫描与代码复用：`unresolved`

每个代码均尝试两个互不重叠窗口：2022-10-01～2024-09-30、2024-10-01～2026-09-30。各窗口少于 800 自然日且预计少于接口 640 根上限；响应要求日期在窗口内、递增且无重复。这只是防止请求上限截断的设计，不证明供应商已返回全部应有 Session。

| 结果 | 代码窗口数 |
| --- | ---: |
| 成功 JSON，非空 day 数组 | 346 |
| 成功 JSON，空 day 数组 | 425 |
| HTTP 501 | 1,228 |
| TLS 失败 | 1 |
| 合计 | **2,000** |

成功非空响应累计 79,270 行，涉及 319 个代码；两个窗口均返回有效数组的代码仅 380 个；620 个代码至少一个窗口未决。已尝试的代码集合恰好为 159000～159999，无重复代码窗口。控制代码 `159919`、`159522`、`159560` 的两个长窗口均未决。

`scan.json` 逐项记录代码、请求窗口、响应状态和行数。**空数组不等于从未上市，非空数组不等于基金身份，更不等于生命周期完整。** 此扫描只覆盖审计窗口，不证明代码在窗口之前从未使用。

由于 cninfo 名录无法完整分页，本轮没有可比较的公告全集，不能生成真实的“行情集合减公告集合”及反向差异，更不能逐项解释差异。全部候选仍待公告核对；没有任何代码获得“已确认复用”或“已确认未复用”的结论。不得把价差、名称相似或当前名录当复用证据，也不得跨上市期间连接行情。

## 3. PIT 规则与来源许可

一手 URL、冻结 hash、请求结果、有效期间缺口见[规则与许可审计](mvp-6-rules-license-audit.md)。

- 深交所法律声明：`http://www.szse.cn/application/laws/index.html`，冻结 10,063 字节，SHA-256 `5398c463263421a98cbf90918dcaa16d6d70ef80f2052a9d0c19c1606ab27936`。须保留“以向他人出售牟利为目的”的条款限定，不能误写成无条件禁止所有非商业下载；反过来也不能把非商业浏览/下载解释为明确授予批量自动化或公开再分发权。
- TDX 授权展示：`https://www.tdx.com.cn/article/license.html` 只能证明供应商展示上游授权，不能证明本项目获得下游使用/再分发授权；用户协议正文未完整取得。
- 腾讯历史接口未取得适用于本项目用途的完整条款/授权；cninfo 免责声明也不是授权书。
- 本轮未取得能覆盖整个窗口、含生效/废止日的 ETF 10%/20% 适用规则及类别映射，也未核实 ETF 首日交易例外、除权除息参考价与舍入规则。规则页面壳或二手题库不作为条文证据；不能套用股票 IPO 无涨跌幅限制规则。

裁决：**许可链和 PIT 规则均 `unresolved`；`reject` 在当前证据下向 public 仓库提交真实数据/原文或默认获准批量抓取的方案。** 这里的 `reject` 是本项目发布方案裁决，不是断言所有原始资料法律上均不能使用。没有新增可用于执行的 limit rule version。
