# ADR 0003：Universe 版本身份与 PIT 成员解析

- 状态：Accepted for Universe v1 implementation
- 日期：2026-09-23
- 契约：[`docs/universe-contract.md`](../universe-contract.md)

## Context

项目要支持可编辑的证券集合和历史指数成分，并允许策略/因子实验引用同一 Universe。当前 `sh000300` 仅有基准指数价格，没有沪深300成员历史；用户今天手工选择的证券也不能代表过去时点可知的历史池。现有实验 JSON 和服务尚无 Universe 身份或写 API。

## Decisions

1. Universe 使用稳定 `universe_id`，每次发布创建不可变 `version_id` 和规范化内容 SHA-256。改名、草稿变更或后续发布不改变既有实验。
2. 用户配置由研究服务在输出目录以原子 JSON 文件管理，并由进程内单写者锁串行更新；serve 不写仓库 DuckDB。历史成分来源事实属于仓库写入侧。
3. 手工成员历史用途标为 `retrospective_static`。指数成员必须有有效区间、真实公开时间、来源引用/快照哈希和覆盖验证；`observed_at` 不是历史发布时间。迟到公告不能回填到其公开前的决策日，未知或有缺口区间在严格 PIT 下拒绝。
4. 解析只对日候选应用成员掩码，保留入池前预热行情与出池后持仓估值/卖出行情。未来收益标签不得参与评分或解析。
5. 动态空池在调仓日产生显式空目标，并在下一可用开盘尝试清仓；不可成交仓位保留且须披露。不得静默保留并把它报告为空仓目标。
6. 股票可被管理，但 ETF Rotation 不接受股票池，直至股票行情、交易单位、费用、状态、公司行动和逐日账本能力全部验证。沪深300成员资料就绪不等于股票回测就绪。
7. 旧实验缺失 Universe 身份时保留可读，标为 `legacy_universe_unknown`，不合成身份且不能匹配指定版本筛选。

## Consequences

配置存储、实验字段、解析器、API 与前端共享冻结的 `docs/universe-contract.md`。历史沪深300回测仍受真实历史成员数据和股票回测能力门槛阻塞；契约或 schema 实现本身不构成完成该能力的证据。
