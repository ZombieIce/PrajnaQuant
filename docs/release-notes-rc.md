# Prajna Quant v0.1.0-rc.1 — Release Notes 草稿

**候选而非稳定版；尚未授权创建 tag 或公开发布。** 负责人须在最终候选 SHA、独立上手、
独立审查及必需 CI 的证据齐备后决定是否接受限定范围。候选压缩包、源码提交、构建工具、
清单和 SHA-256 以本机 `release.json`、`release-files.json`、构建日志与交接记录为准。

## 范围

- 目标平台为 macOS arm64、单用户、loopback 本机研究；发行包包含 release 服务和固定 CLI、
  生产前端、生命周期入口、完全合成示例及[用户指南](user-guide.md)。
- Dataset 查看、D12 日线导入、固定池/共同窗口、手动更新及补充、动量/波动率/严格趋势和标签/IC、
  单 ETF 趋势择时、池内动量 Top-K、策略与持有基准、绩效及可用的现金/持仓/成交明细。
- 复权与公司行动由显式供应文件或固定版本提供；行情发布、价格研究就绪、行动覆盖和总回报
  是不同结论。三池分别以实际输入、覆盖和结果决定可用、受限或未验证，不因预置名单宣称可用。

## 输入与限制

运行需要 Python 3.12、Git、`ps`、与候选构建完全匹配的 `rustc`、浏览器及本机系统动态库；
具体构建/实测系统依赖见构建记录和验收。发行包不依赖开发 checkout、Node、Cargo 或开发 `target`。
真实原始行情、独立交易日历、证券/开盘状态、供应商复权和公司行动事实须由用户按授权准备；
缺失保持 Unknown 或显式失败。采集遵守既有来源和停源规则，不提供替代供应商或自动调度。

Static Universe 有幸存者偏差；不承诺历史 PIT、完整总回报、混合 Venue 公司行动执行、
股票研究、真实全历史、盈利或实盘。新程序产生的 `@3` 等产物可能不能由旧程序读取。
备份与回滚不覆盖或删除不可变输入/结果。独立新用户操作、有限真实验收、最终审查、
必需 CI、系统库与第三方许可证完整核查的结论以交接证据为准，未完成项不得表述为通过。

安装及操作见[用户指南](user-guide.md)；源码与公开的合成验证见项目对应 PR。
真实原文、日志、覆盖、报告及研究身份仅留本机，不进入发布材料。
