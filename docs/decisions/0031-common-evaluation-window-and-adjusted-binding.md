# ADR 0031：共同评价窗口与冻结复权研究输入绑定

- 状态：Accepted，MVP-7 #297/T08a；依据 Spec #286 D4/D5、[ADR 0030](0030-supplier-adjusted-research-series.md)
  与负责人 2026-10-29 T08a/T08b 拆分裁决。

## 背景

Spec #286 要求页面显示池成员的最大共同可用区间，并按最长预热从共同就绪日
评价所有参数和基准，预热不计成交或绩效。T07 已交付显式供应商复权研究序列，
但其契约把任务接线留给消费票；T04b 的单证券买入持有仍只冻结原始价 DSV、
Universe 与成本，没有评价窗口。若只按原始 Bar 覆盖计算窗口，会违反
“研究信号使用复权价、成交用原始价”的价格职责分离；若把窗口留给运行期
重新推导，又会与冻结身份脱节。

负责人裁决：(1) T08a 负责 adjusted version 绑定、共同窗口/最大预热计算、
冻结 Experiment/Run 身份、Rust 执行边界与独立合成 golden；(2) T08b 负责
预检 CLI/HTTP、页面与浏览器 E2E；(3) 成交和账户估值继续用原始 Bar，复权
序列只作研究输入；(4) 保留 T04b/T04d 单证券原始价旧路径与旧身份。

## 决策

1. **绑定进入定义与身份。** 选择请求新增逐成员 `adjusted`；池提交必须绑定，
   单证券可选（省略即旧路径）。冻结定义新增 `adjusted_versions` 与
   `evaluation`（`common-window@1`），两者进入 Experiment 规范身份与 Run Spec。
   执行侧 `Experiment::parse` 重新读取并校验版本、raw DSV、证券、覆盖与窗口
   顺序，失败 fail closed；不选 latest、不回退其他版本或原始价。
2. **窗口按冻结复权覆盖计算。** 每成员研究覆盖取绑定复权行的真实 Session
   存在性；共同窗口是各成员首/末复权行交集；参数就绪要求尾随
   `warmup_sessions + 1` 个 Session 对所有成员完整。缺口只后移评价起点，不
   删除 Session、不填零、不以原始价替代研究信号。窗口至少两个 Session；
   任一比较参数历史不足即不可运行，拒绝冻结提交。
3. **执行只评价窗口内 Session。** Fast Event 与 Vector 把账本 Panel 切片到
   `[start, end]`：预热不产生 Decision/Fill/绩效，结果/Summary 从评价起点开始，
   窗口末 Decision 不成交、窗口后不执行。Buy & Hold 的建仓锚点改到窗口首个
   Session；其它策略保留完整 Panel 的预热计算并过滤窗口外 Decision。
4. **价格职责不变。** 复权行只提供研究覆盖；成交、估值、成本、公司行动与
   账户恒等式沿用原始 Bar 账本。窗口是身份承载的定义输入，不改 Fast/Vector
   语义版本；无 `evaluation` 的旧定义身份与结果不变。
5. **预检/页面后置。** T08b 复用 `selection::plan` 库函数提供 CLI/HTTP/页面与
   浏览器验证；T08a 不新增页面或预检端点。T08 完整产品验收等待 T08b。

## 考虑过的方案

- **只按原始 Bar 覆盖计算窗口**：实现更小，但把研究信号可用性建立在原始价上，
  违反负责人“必须绑定复权版本”的裁决，且后续因子入口会绕过绑定。
- **运行期按 latest/当前 lake 重新推导窗口**：与冻结身份脱节，旧结果会随输入
  变化改写，违反 D9/ADR 0018。
- **把窗口作为每个 Run 的 Strategy 参数**：破坏“同一批比较共用窗口/基准”的
  语义，且基准与策略无法保证同窗口。
- **复制一套窗口账本**：会建立第二套执行核心，且无法保证与现有账本一致性。
- **提升 Fast/Vector 语义版本**：窗口作为定义输入已进入 Run Spec，旧 spec 与
  结果不变；同一新 spec 在新代码下确定，故不提升引擎语义版本。

## 后果

- 池/单证券任务可用显式复权版本冻结一个共同的、不可漂移的评价窗口；已有
  旧定义、旧任务与旧结果身份不变。
- 复权版本损坏、DSV/证券不符、空序列、覆盖不足或窗口过短都在冻结/解析处
  显式失败；评价窗口内缺口保留为 warning，不伪造完整覆盖。
- 真实行情、完整 PIT、历史可用时刻与公司行动总回报仍未验证；公开验证只用
  合成数据。页面与预检由 #356/T08b 承接，T08 完整验收不因本 ADR 提前完成。
