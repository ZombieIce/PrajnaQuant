# ADR 0030：供应商复权研究序列与原始成交价格分离

- 状态：Accepted，MVP-7 #296；依据 Spec #286 D5 与负责人单票预算裁决。

通用 `cn-stock-etf-daily` Dataset 继续保存原始价。供应商回溯复权序列作为
独立不可变研究输入导入，不替换 `bars`，不修改既有 DSV、Run 或 MVP-6 身份。
其版本以 `adj:sha256:<原始导入文件字节的 SHA-256>` 标识，文件包含原始 DSV、
证券、方法/来源版本、观察时刻、追溯/收盘可用假设、声明区间及供应商 OHLC。
相同字节幂等；内容或格式修订都形成新版本，无隐式 latest。原始导入文件原样保留。

Rust 导入器只校验和读取供应商提供的精确价格，不推导公司行动、分红金额或
调整因子。研究使用者显式冻结 `(raw_dsv, adjusted_version)`，按版本读取。
本票提供该 Rust/CLI 输入接口，后续因子/任务接线由相应票承担。

成交和估值继续走原始 Bars；调整价格没有账户/成交适配器。现金分红与数量
变化只来自独立公司行动/账本入口，不能再叠加复权收益。ADR 0023 的 MVP-6
顺序 TRI 与事件核对身份保持原样；本序列不被称作该 TRI 或严格 PIT 输入。

历史发布时间保持 Unknown，`observed_at` 只是本地观察时间。
供应商后来事件可能改写历史、研究按收盘可用的假设必须显式保存并在页面展示。
缺失不补零、不删 Session、不推断停牌；导入行必须有对应原始 Bar 和 Session。
页面只读 Rust 固定版本和覆盖结果，不做价格/收益计算。

本机根目录由导入/读取 CLI 的显式 `--root` 指定（`serve` 的 Dataset 根仍为
`--dataset-root`），拒绝 MVP-6 存档与已有符号链接输出路径。
公开验证只用合成输入；真实来源/实际覆盖及明细仍只留本机。
