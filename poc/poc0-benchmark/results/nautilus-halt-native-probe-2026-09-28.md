# Ticket 14: Native Nautilus HALT order lifecycle

Run from repository root: `.venv/bin/python poc/poc0-benchmark/nautilus_halt_probe.py`.
Environment: NautilusTrader 2.0.0rc5, Python 3.12.2, macOS ARM64.
Execution HEAD: `e89d65de1fc62afae919438fb2c0fd9c12e9f75d`; uncommitted probe SHA-256: `ce90e7347ad1f9c181f9f79c55b3f51d86c10d1c239abeac12a9ae678f61be4a` (replay against the committed revision for an exact code identity). The worktree also contained unrelated changes. No build dependencies were added.

One `PROBE.SIM` Equity, cash USD 10,000, a 99.00/100.00 bid/ask QuoteTick (size 100 on each side), and one buy market order for one share. All timestamps below are Unix nanoseconds. The `BacktestEngine` receives the quote at `1767756600000000000`. In the HALT arm it then receives `InstrumentStatus(action=HALT)` at `1767756601000000000`. In both arms the strategy schedules `submit_order()` directly for `1767756601001000000`, after HALT is effective; `run(end=1767756601002000000)` advances the engine through the timer without a second quote. No project Adapter status gate participates. The control differs only by omitting the HALT event.

| Arm | Native callback sequence (ts in ns) | Engine cache order state | Outcome |
| --- | --- | --- | --- |
| No HALT | quote observed → submit → submitted → filled at 100.00 (`1767756601001000000`) | `FILLED` | filled |
| HALT | quote observed (`1767756600000000000`) → HALT observed (`1767756601000000000`) → submit → submitted → rejected (`1767756601001000000`) | `REJECTED` | `on_order_rejected` |

Rejection reason from native callback: `Market PROBE.SIM is CLOSED, cannot accept order O-20260107-033001-001-000-1`. The order ID is generated by Nautilus; the replayed run may have a different ID. The script prints the complete event streams and asserts the control fill price and both cached terminal states. The locally retained order object is initially `INITIALIZED`, so only the engine cache's terminal state is reported. Missing pinned wheel or engine errors yield `Unknown` with an error; no unobserved lifecycle is classified as a falsification.

**Conclusion:** Confirmed for this fixed version and isolated quote/status/order sequence: Nautilus rejects the market order submitted during HALT. MVP-4 may consider using native status handling instead of synthesizing this gate in the Adapter, subject to separate integration tests. This does not change the current Adapter behavior, existing A-share/ETF execution timing, or ADR 0012's B2 comparison scope.
