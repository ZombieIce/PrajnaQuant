# 初级产品目标与交付路线

状态：产品目标，非现有功能清单。现状与正确性阻断以 [`STATUS.md`](STATUS.md) 和实际代码/测试为准；ETF Rotation 是首个纵向验证场景，不是平台的范围上限。

## 初级产品目标

建设可在本机运行、并可部署到服务器供授权用户远程访问的 A 股股票与 ETF 日频研究回测平台。日频数据在交易日后自动增量同步。用户可管理和选择选股池（Universe），用因子研究与策略回测分析历史数据，并在网页查看因子评价、策略组合绩效、选股池以及股票/ETF K 线。

初级目标不等于实盘交易、分钟级交易或已经拥有无偏的全历史 A 股数据库。任何历史业绩都必须附带数据来源、快照/版本、Universe 的历史可知性、价格/分红口径和交易假设。

## 职责与契约目标

| 层 | 初级产品职责 | 当前实际状态 |
| --- | --- | --- |
| Rust 数据层 | 证券主数据、交易日历、日频 OHLCV、修订/原文、数据质量审计、增量同步 | 已有版本化仓库、显式范围增量同步/恢复与不可变发布；隔离股票+ETF 小样本通过，生产回填/调度和完整 PIT 名录未验 |
| Rust 研究/回测层 | 股票/ETF 通用快照、Universe 解析、因子执行契约、组合回测、成本/账户/指标 | 显式证券列表的股票/ETF 通用冻结快照已有代码与合成测试；ETF Rotation 执行审计和五 ETF 版本复跑已接通，真实旧快照仍为 bar-only；股票回测被能力门槛阻断 |
| Python 研究层 | 探索分析、因子原型、统计实验，与 Rust 共享有版本/可用时刻的输入和输出 | 仅早期 `warehouse.py` 入库原型；无研究包或正式互通契约 |
| Rust API | 数据、因子、策略、选股池、结果和运行作业的服务契约 | 已有本地只读结果、Universe CRUD/筛选及固定发布快照证券/日线查询；无作业提交或远程认证，真实股票查询未验 |
| React 前端 | 因子评价、组合绩效、选股池管理、股票/ETF K 线及运行状态 | 已有报告、Universe 管理和股票/ETF K 线/成交量页面；后者只在合成快照验收，成交/成本明细及新运行流程尚缺 |
| 运维 | 交易日后自动同步、失败重试和告警、备份、受控远程访问 | 本地 CLI/loopback 服务与 macOS 调度模板存在；模板未安装/启用，无认证或服务器部署配置 |

跨层原则：Rust 是回测账本、成本、绩效和对外报告的权威；Python 的因子实验必须记录因子 ID/版本、参数、输入快照、观察与可用时刻，不能悄悄成为第二套回测引擎；React 通过 API 消费数据，浏览器不得负责权威量化计算。现有时序为 T 日收盘信号、下一有行情日开盘模拟成交，详见 [`time-model.md`](time-model.md)；扩展股票执行前必须审查交易状态、手数、费用/税和公司行动。

## 分阶段交付与验收

以下顺序是交付依赖，不表示后面的工作必须等待所有真实历史指数成分均取得。目前按用户要求，沪深300历史成分只用合成 fixture 验证接口与时序，不把模拟公告时间当真实 PIT 证据。

1. **冻结可信数据与回测边界。** 缺 bar 后的整次延期、目标替换和状态拒单已有合成手算测试，五 ETF 已发布版本/固定快照的旧 bar-only 复跑与 API/UI 闭环已完成。下一道门槛是可信历史执行状态来源及可知时刻、带状态快照真实复跑；继续披露当前 ETF 名单的幸存者偏差与未复权价缺分红。验收：固定小样本可复算每日成交、现金、数量、成本、NAV 和持仓上限，真实状态源与执行模式可追溯；所有限制留在实验结果。
2. **建立股票与 ETF 共用的日频数据闭环。** 定义证券主数据、上市/终止、交易日历、OHLCV、复权/分红与交易状态的来源及可用时刻；完成可断点的每日增量同步、原文/hash、重复运行幂等、缺日/修订审计和只读研究快照。验收：指定股票和 ETF 的连续交易日样本可对照独立日历，增量任务重复运行不制造重复有效行，失败任务可恢复并可查状态。当前“已观察集合”不得称为历史全市场。
3. **扩展 Rust 通用回测与因子接口。** 在冻结时间模型、Universe 版本和快照身份的前提下，支持股票及 ETF；为两类资产分别定义手数、费用/税、停牌/缺价、涨跌停等可执行性；形成统一的因子输入/输出与策略配置契约。验收：股票和 ETF 合成场景均有手算金标准、账本恒等式、成本明细、无未来信息测试。真实指数历史成员须等 PIT 数据证据可用后才开放相应真实历史运行。
4. **接入 Python 因子研究层。** 建立研究包与 Rust 可复用的快照/因子结果契约，保存因子元数据、版本、参数、日期、证券、值和数据身份；区分研究标签和可交易信号。验收：同一不可变输入可复现因子结果，Rust 能读取并检查版本/可用时刻；Python 不重算权威账户和绩效。
5. **补全 API 与网页。** 提供有边界的行情/K 线查询（证券、复权口径、时间范围、分页或降采样）、因子/策略/Universe 查询及异步回测作业状态；网页接入因子评价、组合净值/回撤/基准与超额、持仓/交易/成本、Universe 管理和股票/ETF K 线。验收：页面数据与服务端结果一致；十年级序列查询不会依赖一次返回全部 JSON；新运行可追溯到配置和快照。
6. **完成日更自动化和远程部署。** 在交易日数据发布后运行同步/审计/快照更新，记录任务状态与失败重试；提供服务器部署、配置/密钥管理、认证授权、HTTPS、备份与恢复说明。验收：新服务器按文档部署后，授权用户可远程查看数据与报告；模拟一次日更失败可恢复，未授权用户不能访问写入/运行接口。
