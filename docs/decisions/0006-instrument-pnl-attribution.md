# ADR 0006：逐标的盈亏归因口径

- 状态：Accepted
- 日期：2026-09-24

## Context

策略绩效页面需要按标的呈现盈亏。现有账户账本只保留现金、持仓数量和逐笔成交；若直接按期末市值减买入金额，部分卖出、重复买入及交易费用会导致归因失真。

## Decision

Rust 回测报告在期末按标的生成 `instrument_performance`，使用移动加权平均成本法：

- BUY 增加数量；成交额、佣金和税加入该标的成本基础。
- SELL 按卖出前的单位平均成本分摊成本；成交额扣除佣金和税后减去分摊成本，记为已实现盈亏。
- 成交价已包含配置滑点，不能在损益计算中再次扣除滑点成本。
- 未平仓数量按最后可用收盘价估值，市值减剩余成本记为浮动盈亏。
- 逐标的总盈亏之和应等于期末组合权益减初始资金；当前现金收益为零。

报告同时保存每日持仓快照，资金占用率定义为证券持仓市值合计除以当日组合权益。前端按回测选择日期范围筛选每日曲线；逐标的盈亏表按完整回测期展示。

新增序列字段使用 serde 默认空数组以兼容既有报告文件，但不反向重建旧报告数据。

## Consequences

该口径可解释单标的买卖和费用归属，并通过账本守恒测试验证。它不包含分红、拆分、融资利息或其他公司行动；无效/缺失收盘价也不会被假定为可成交价格。需要更换成本法或增加现金收益时，应同步版本化口径并补固定账本测试。
